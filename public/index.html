📈 Калькулятор APACHE II

Оценка тяжести состояния по наихудшим значениям за первые 24 часа пребывания в ОРИТ.

Острые физиологические показатели

При FiO₂ <50% вводите PaO₂, мм рт. ст.

Возраст и хроническое состояние

APACHE II — прогностическая шкала для оценки тяжести и группового риска, а не самостоятельный прогноз для конкретного пациента и не основание для ограничения лечения. Используйте наихудшие значения за первые 24 часа. Учитывайте влияние седации на GCS. Результат требует клинической проверки.
