MEDPILOT AI 0.5 — PWA для iPhone

ВАЖНО
Это прототип, а не сертифицированное медицинское изделие. Ответы ИИ могут содержать ошибки. Не вводите ФИО, даты рождения, номера медкарт и другие идентификаторы пациентов. Перед клиническим применением необходимы проверка врачом, клиническая валидация, аудит безопасности и правовая оценка.

ЧТО ВНУТРИ
- PWA-интерфейс с каталогом медицинских специальностей.
- Серверный API для OpenAI; ключ не хранится в браузере.
- Базовые расчёты ИМТ, среднего АД, шокового индекса и анионного интервала.
- Ссылки на внешние медицинские библиотеки.
- render.yaml для развёртывания на Render.

РАЗВЁРТЫВАНИЕ
1. Создайте Git-репозиторий и загрузите в него содержимое архива.
2. В Render создайте Blueprint из этого репозитория (render.yaml).
3. В настройках сервиса добавьте секрет OPENAI_API_KEY. Не отправляйте ключ в чат и не добавляйте его в исходный код.
4. Укажите актуальную поддерживаемую модель в OPENAI_MODEL, если требуется.
5. Дождитесь успешного деплоя и откройте HTTPS-адрес.

УСТАНОВКА НА iPHONE
1. Откройте HTTPS-адрес приложения в Safari.
2. Нажмите «Поделиться».
3. Выберите «На экран Домой» / Add to Home Screen.
4. Подтвердите добавление.

ЛОКАЛЬНЫЙ ЗАПУСК
Требуется Node.js 20+:
npm install
Задайте OPENAI_API_KEY в окружении сервера.
npm start
Откройте http://localhost:3000

БЕЗОПАСНОСТЬ
- API-ключ хранится только в переменных окружения сервера.
- Ограничен размер JSON-запроса и частота обращений.
- Тела клинических запросов не записываются в логи приложения.
- Перед реальным использованием требуется независимый аудит и настройка хранения/обработки данных согласно применимому законодательству.
